# Advanced Sales Forecasting Dashboard (Power BI)

An end-to-end Power BI analytics project featuring custom DAX-based tables/
columns and a sales forecasting model, with finalized reports exported as 
shareable PDFs.

## What I did
- Cleaned and modeled data in Power BI
- Wrote custom DAX queries for calculated tables and columns
- Built a forecasting model to generate predictive sales insights
- Designed a professional, presentation-ready dashboard

## Skills used
Power BI, DAX, Power Query, Forecasting, Dashboard Design
